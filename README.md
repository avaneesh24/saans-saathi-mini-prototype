Saans Saathi Mini 🌿

An AQI-Based Outdoor Activity Safety Advisor

Saans Saathi Mini is a beginner-friendly Python project designed to help users understand air quality and make more informed decisions about outdoor activities.

The program takes the user's age group and current AQI value as input, then provides general air-quality precautions and activity guidance.
#SAANS-SAATHI MINI prototype
🎯 Objective

To make air-quality information easier to understand, particularly for children, adults, and older adults who spend time outdoors.

✨ Features

- Age Group Selection: Categorizes users into four age groups.
- AQI Input: Accepts AQI values from 0 to 500.
- AQI Categorization: Classifies air quality using India's AQI category ranges.
- Activity Guidance: Provides general recommendations about outdoor exertion, including running, intense sports, and walking.
- Input Validation: Handles invalid inputs and out-of-range AQI values.
- Safety Precautions: Displays reminders to follow official guidance and take extra care when necessary.

🛠️ Technologies Used


- Conditional statements ("if-elif-else")
- Functions
- Exception handling ("try-except")
- Input validation
- Basic logical operations

🚀 Future Improvements
